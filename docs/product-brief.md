# Flowboard — product brief

## Positioning

Flowboard is a modern realtime project workspace for small teams and solo makers.

Core promise: **Plan. Focus. Ship.**

The product uses a familiar Kanban workflow but adds a lightweight **Project Pulse** layer that summarizes progress, blockers, deadlines, and attention areas without becoming a second analytics product.

## Product principles

1. Familiar in five minutes.
2. Realtime collaboration should feel native, not bolted on.
3. Visual hierarchy over feature density.
4. Every workspace should answer “what needs attention?” quickly.
5. Free/demo access should make the product understandable before signup.

## MVP

- Landing and public demo
- Authentication
- Workspaces and workspace members
- Boards, lists, cards
- Drag and drop
- Labels, priority, due dates
- Checklists, comments, attachments
- Activity history
- Realtime presence and board changes
- Roles: owner/admin/member/viewer
- Workspace overview and Project Pulse
- Templates
- Responsive desktop/mobile layouts
- Dark/light theme

## Deferred

Billing, AI, external integrations, automation rules, advanced analytics, public API, native mobile app.

## Launch path

1. Private local MVP
2. Supabase + Liveblocks integration
3. Production safety/RLS and error states
4. Vercel preview
5. Public beta
6. Landing/SEO/OG screenshots
7. Product feedback loop
